# Observe — AI Automation, Web & App Development Studio

Observe is a high-fidelity digital studio landing page utilizing a dark-mode, glassmorphic layout powered by the **Liquid Glass** design system.

## 🌟 Features
- **Liquid Glass Containers:** Custom CSS gradient borders with exclusion masks and backdrop-filter blur.
- **Continuous Ambient Video Background:** 0.5x speed abstract slow-motion video loop.
- **Instrument Serif Typography:** Layered text shadows for razor-sharp legibility over dynamic video frames.
- **Three Engineering Pillars:**
  - AI Automation & Autonomous Agent Systems
  - Cinema-grade Next.js Web Development
  - Full-stack Cross-Platform Mobile Apps
- **Interactive Tools:**
  - Interactive Tech Stack Explorer
  - Real-time Project Cost & Timeline Estimator
  - Direct Lead Inquiry Form & Consultation Booking Modal

## 🚀 Getting Started
Simply open `index.html` in your browser, or serve it with any local server:

```bash
# Python
python -m http.server 8000

# Node
npx serve .
```
